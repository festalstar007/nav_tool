## 最小 MVP

- 单管理员初始化、登录、退出和修改密码。
- 左侧多级分类，点击筛选当前分类及子分类。
- 右侧紧凑网格，图标和书签名为主，长名称和备注通过提示查看。
- 跨分类搜索名称、网址及备注。
- 分类和书签的新增、编辑、删除，书签跨分类移动。
- 编辑模式拖拽排序；书签提供前移、后移按钮，同级排序使用完整 ID 列表和数据库事务。
- HTML 导入预览与确认，同分类内去重，保留层级及顺序，提取导出文件内嵌图标。
- 图标缺失时使用名称占位，支持手动获取公共网站 favicon。

本地备份、保留策略、后台状态、归档下载及新目录恢复已有基础实现。定时备份默认关闭；异地备份仅保留存储接口。按用户最新要求，当前不扩展这些功能，以核心导航体验为先。

## 实施中确定的规则

- SQLite 使用纯 Go 驱动 `modernc.org/sqlite`，Go 工具链由 `go.mod` 固定。
- 分类允许多级，导入最高 64 层；非空分类禁止直接删除。
- 每个书签记录属于一个分类，跨分类可存在相同网址。
- HTML 导入最大 16 MB、单次最多 20000 条，HTTP/HTTPS 以外链接跳过；根层书签放入“未分类”，同名同父分类合并。
- 本地备份默认候选参数为每天 03:00、Asia/Shanghai、保留 7 份，需在后台开启。
- 恢复通过命令行执行，仅写入不存在的新目录，不提供直接覆盖在线数据的按钮。
