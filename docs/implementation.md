## 实施中确定的规则

- SQLite 使用纯 Go 驱动 `modernc.org/sqlite`，Go 工具链由 `go.mod` 固定。
- 分类允许多级，导入最高 64 层；非空分类禁止直接删除。
- 每个书签记录属于一个分类，跨分类可存在相同网址。
- HTML 导入最大 16 MB、单次最多 20000 条，HTTP/HTTPS 以外链接跳过；根层书签放入“未分类”，同名同父分类合并。
- 本地备份默认候选参数为每天 03:00、Asia/Shanghai、保留 7 份，需在后台开启。
- 恢复通过命令行执行，仅写入不存在的新目录，不提供直接覆盖在线数据的按钮。
